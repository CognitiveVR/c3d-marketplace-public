

The AI coding agent Code Puppy doesn't support connecting to a plugin marketplace like Claude Code does, but does support skills in a similar format. This folder is for publishing skills to Code Puppy.

## Usage

To use one of these skills, just download it (a zip of each whole skill folder is available for convenience) and place it in your `~/.code_puppy/skills` folder.

## Maintenence

There are some minor differences in the folder structure of the skill but the contents of these skills should otherwise be the same.

All files are top level instead of most files being nested below "SKILL.md" in a "references" folder. Otherwise, the files should match 1:1. In the case of the public API skill, I have also made some minor changes in the authentication section between the Claude and Code Puppy versions that should be maintained.
